## Projects

A mix of **backend engineering, automation, and systems work**:

- [**drf-commerce-engine**](https://github.com/NWGKGIT/drf-commerce-engine)
  A Django REST Framework e-commerce API with payment integration (Chapa), inventory management, and asynchronous task processing with Celery and Redis.

- [**git-dr-mirror**](https://github.com/NWGKGIT/git-dr-mirror)
  A one-way disaster-recovery mirror of your GitHub repositories to GitLab, with retries, run locking, and scheduled runs.

- [**git-identity-manager**](https://github.com/NWGKGIT/git-identity-manager)
  A CLI that switches your Git name, email, and SSH key per repository with a single command.

- [**VoidGram**](https://github.com/NWGKGIT/VoidGram)
  A keyboard-driven, terminal-based Telegram client built for focused, distraction-free messaging.

- [**social-block**](https://github.com/NWGKGIT/social-block)
  A multi-layer, self-obfuscating blocker for LinkedIn, X, Pinterest, Reddit, Instagram, Telegram, Threads, and Quora.

- **TeleGlance**
  An API-free library for scraping public Telegram channels. Published on npm and PyPI.

- **AGQ**
  A local-first desktop quota monitor written in Go (Wails + SQLite), with a local JSON API for usage analytics.

- **HTTP Server from Scratch**
  An HTTP/1.1 server in Go with no external frameworks: TCP handling, request parsing, routing, and response serialization.

More work is on my profile, and new projects are on the way.
